# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities privately to the project owner via
the RapidAPI listing contact (rapidapi.com/CooLCHI-gun/api/sanctions-screening-api)
or the live service contact at https://sanc.mooocopy.com.

**Do not** open a public issue for security vulnerabilities.

## Disclosure Timeline

- Acknowledgement: within 48 hours
- Fix + notification: as soon as practical, typically within 7 days for
  critical issues

## Scope

- The live API service (https://sanc.mooocopy.com)
- The RapidAPI gateway proxy layer
- This repository's source (HTTP API layer)

## Out of Scope

- The proprietary matching engine and data pipeline (not in this repo)
